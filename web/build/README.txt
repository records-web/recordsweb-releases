RecordsWeb desktop application icon
===================================

Place the Windows application icon at:

  build/icon.ico

Electron will use it during local development when the file exists, and the
build directory is included in packaged builds. Keep this desktop application
icon bundled with the application; the Grove Way organisation logo is managed
separately through Supabase Storage.

A Windows .ico containing several sizes (including 16, 32, 48 and 256 px) is
recommended.
