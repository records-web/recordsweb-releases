# RecordsWeb 2.5.9 — Documents and fit notes

Run `supabase/recordsweb-2.5.9.sql` once in the Supabase SQL Editor before using structured fit notes.

Changes:
- Every document is displayed as a distinct record rather than a continuous text block.
- Fit notes use a structured data-entry workflow with no on-screen form preview while issuing.
- Issued fit notes are filed in Documents with condition, advice, period and issuer information kept as separate sections.
- Fit notes can be printed/saved from the filed document. The generated printout is deliberately watermarked as a RecordsWeb prototype and is not a statutory fit note.
