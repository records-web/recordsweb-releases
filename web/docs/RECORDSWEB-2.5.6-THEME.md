# RecordsWeb 2.5.6 - Light and dark mode

RecordsWeb now includes a persistent Light/Dark workspace theme.

- Use the **Dark mode / Light mode** control in the bottom-right status bar for an immediate switch.
- The selected theme is stored in the existing local workstation settings and is restored on the next launch.
- The same preference can also be changed from **Settings > Display > Colour theme**.
- Compact login and update windows follow the saved theme.

No Supabase schema or Edge Function changes are required for this release.
