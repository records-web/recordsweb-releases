# RecordsWeb 3.4.3 — Problems layout

The patient Problems record now uses a dense clinical list layout based on the supplied reference.

- Active Problems and Significant Past Problems are shown together on one page.
- Each problem has a compact A-Z / numeric reference marker.
- Significance is shown inline in brackets rather than as a separate table column.
- Selecting a row opens the existing problem editor, preserving status, dates and notes without cluttering the main list.
- Patient Summary now uses the same compact problem presentation.
- Search continues to filter both active and past problems.
- Light and dark RecordsWeb themes are supported.
