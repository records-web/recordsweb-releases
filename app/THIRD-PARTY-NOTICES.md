# Third-party notices

## XION-ChaseCam

RecordsWeb Policing's bodycam viewer overlay layout is adapted from XION-ChaseCam by `zhivotnoya`.

Source: https://github.com/zhivotnoya/XION-ChaseCam

The repository describes the HTML/JavaScript overlay as free-to-use for roleplay streamers. RecordsWeb reimplements the layout for its LiveKit viewer and does not redistribute the repository's bundled font files or AXON-branded image artwork.

## LiveKit

RecordsWeb uses LiveKit Cloud as the WebRTC media service for live bodycam streaming. LiveKit client JavaScript is loaded from the pinned `livekit-client@2.22.3` browser bundle. LiveKit credentials and token signing remain server-side.
